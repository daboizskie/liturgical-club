Email & SMTP Settings

How Email Sending Works

Option 1 — Brevo (Recommended)

Create a free account at brevo.com, get your API key, and paste it below. Free tier sends up to 300 emails/day. Set BREVO_API_KEY and SENDER_EMAIL as environment variables on Render.

Option 2 — SMTP (Gmail, etc.)

Use Gmail App Password: set host = smtp.gmail.com, port = 587, user = your Gmail, pass = 16-char app password. Set all as environment variables on Render.

Current Email Configuration

These values come from environment variables set on your hosting platform (Render, Railway, etc.). You cannot edit them here — set them in your Render dashboard under Environment → Environment Variables.

VariableStatusWhat to set
BREVO_API_KEY {% if config.get('BREVO_API_KEY') or '' %} Set ✓ {% else %} Not set {% endif %} Your Brevo API key (xkeysib-…)
SENDER_EMAIL {% if config.get('SENDER_EMAIL') or '' %} Set ✓ {% else %} Not set {% endif %} The From address (must be verified in Brevo)
SMTP_HOST {% if config.get('SMTP_HOST') or '' %} Set ✓ {% else %} Not set {% endif %} smtp.gmail.com or your provider
SMTP_PORT Default 587 587 (TLS) or 465 (SSL)
SMTP_USER {% if config.get('SMTP_USER') or '' %} Set ✓ {% else %} Not set {% endif %} Your SMTP login email
SMTP_PASS {% if config.get('SMTP_PASS') or '' %} Set ✓ {% else %} Not set {% endif %} App password (Gmail) or SMTP password
Step-by-Step: Set Up Gmail Sending
  1. 1 Go to your Google Account → Security → 2-Step Verification (enable it if not already).
  2. 2 Go to myaccount.google.com/apppasswords → create a new app password → name it "Liturgical Club".
  3. 3 Copy the 16-character password shown.
  4. 4 In Render → your service → Environment: add SMTP_HOST=smtp.gmail.com, SMTP_PORT=587, SMTP_USER=youremail@gmail.com, SMTP_PASS=the16charpassword, SENDER_EMAIL=youremail@gmail.com.
  5. 5 Redeploy the service. Email will now send on every new application.
